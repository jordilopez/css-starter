# Code

Styles `code`, `kbd`, `samp`, and `pre` for inline and block code. There are no
`--code-*` tokens — the feature styles the native elements directly with the
shared design tokens. Font sizes use relative `em` units intentionally so code
scales with the surrounding text and keeps its proportion in any context.

## Tokens

None. This feature has no component-specific tokens; see the global **Tokens**
story for the shared colour, radius, spacing, and `--ff-mono` scales it uses.
