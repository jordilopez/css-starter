# Blockquote

Styles the native `<blockquote>` element with an inset quote appearance: a
coloured left border, secondary text colour, and top/bottom spacing.

All values reference the shared token scales — there are no feature-specific
`--blockquote-*` tokens.

## Tokens

None. This feature has no component-specific tokens; it uses shared tokens
directly:

| Token used            | Purpose                |
| --------------------- | ---------------------- |
| `--sp-4`              | Vertical margin, left padding |
| `--c-primary`         | Left border accent colour |
| `--c-text-secondary`  | Quote text colour      |
