# Form

Styles `label`, `input`, `textarea`, `select`, `fieldset`, and `legend`, plus
custom-styled native checkboxes and radios (`appearance: none` with CSS
pseudo-elements for checked / indeterminate states). There are no `--form-*`
tokens — the feature styles the native elements directly with the shared
design tokens.

## Tokens

None. This feature has no component-specific tokens; see the global **Tokens**
story for the shared colour, radius, spacing, type, and transition scales it
uses.
