# Typography

Styles headings (`h1`–`h6`), paragraphs, inline text (`strong`, `em`,
`small`), blockquotes, lists, and horizontal rules. There are no `--type-*`
tokens of its own — the feature styles the native elements directly with the
shared type, colour, and spacing scales.

## Tokens

None. This feature has no component-specific tokens; see the global **Tokens**
story for the shared type, colour, and spacing scales it uses.

> `small` uses a relative `0.85em` font size (not a token) so it scales with
> its surrounding text.
