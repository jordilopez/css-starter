# Link

Styles the native `<a>` element. Disabled links are keyed off
`[aria-disabled='true']` so consumers emit the attribute and inherit the
disabled look — no per-framework CSS required. There are no `--link-*` tokens —
the feature styles the native element directly with the shared design tokens.

## Tokens

None. This feature has no component-specific tokens; see the global **Tokens**
story for the shared colour and transition scales it uses.
